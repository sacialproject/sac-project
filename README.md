## What is SAC PROJECT

**SAC PROJECT** is an open scientific and social initiative developing a theory and a bilingual assessment tool for **Social Adaptation Capital (SAC)** — the meta-skills that allow a person to enter new professional and social environments, withstand uncertainty, and preserve agency.

The core idea: any work or life experience — from a jewelry workshop to a construction site — converts into transferable meta-skills **through reflection**. No experience is wasted if it is consciously processed.

---

## Theory in brief

### 7 components of adaptive capital

| Component | Description |
|---|---|
| Cognitive | Environment analysis, planning, cognitive flexibility |
| Emotional | Self-regulation, empathy, stress resilience |
| Communicative | Negotiation, boundaries, teamwork |
| Volitional | Discipline, patience, follow-through |
| Ethico-legal | Justice, rights awareness, solidarity |
| Aesthetic | Sense of form, quality, beauty |
| Career | Learnability, adaptability, reflection |

### 8 mechanisms of experience conversion

1. Conversion — experience → meta-skill through reflection
2. Transfer — applying meta-skills in new contexts
3. Scanning — reading norms, rules, hierarchies
4. Appraisal — assessing resources and risks
5. Trial — small experiments and feedback
6. Boundary regulation — adapt, negotiate, defend, or exit
7. Sensemaking — narrative of "why am I here"
8. Social exchange — networks, mentors, solidarity

### 3 levels of interaction

- **Micro** — individual reflection and regulation
- **Meso** — group, team, organization
- **Macro** — labor market, culture, institutions

### "3D" protocol for practice

- **Diagnosis** — map experience, environment, boundaries, SAC profile
- **Design** — plan small trials, train mechanisms, find support
- **Debriefing** — reflect after each trial, rebuild identity, transfer

## Assessment battery

The interactive tool is a **5-module multimodal battery**, bilingual (RU / EN), ~25 minutes, anonymous, no registration.

| Module | Content | Time |
|---|---|---|
| 1. Situational Judgment Test | 12 scenarios | ~7 min |
| 2. Cognitive micro-tests | Rule switching, sequences, working memory | ~6 min |
| 3. Emotional vignettes | 6 scenarios | ~4 min |
| 4. Self-report scale | 21 items | ~4 min |
| 5. Reflective block | 3 open questions | ~3 min |

After completion, a personal report is generated with a 7-component profile, tags (resource / deficit / balanced), interpretation, and recommendations based on the "3D" protocol.
