## Что такое SAC PROJECT

**SAC PROJECT** — это открытый научно-социальный проект, развивающий теорию и двуязычный инструмент диагностики **социально-адаптационного капитала (САК)** — метанавыков, которые позволяют человеку входить в новые профессиональные и социальные среды, выдерживать неопределённость и сохранять субъектность.

Ключевая идея: любой трудовой или жизненный опыт — от ювелирной мастерской до стройки — конвертируется в переносимые метанавыки **через рефлексию**. Ни один опыт не потерян, если он осмыслен.

## Теория кратко

### 7 компонентов адаптивного капитала

| Компонент | Описание |
|---|---|
| Когнитивный | Анализ среды, планирование, гибкость мышления |
| Эмоциональный | Саморегуляция, эмпатия, стрессоустойчивость |
| Коммуникативный | Переговоры, границы, работа в команде |
| Волевой | Дисциплина, терпение, доведение до конца |
| Этико-правовой | Справедливость, знание прав, солидарность |
| Эстетический | Чувство формы, качества, красоты |
| Карьерный | Обучаемость, адаптивность, рефлексия |

### 8 механизмов конверсии опыта

1. Конверсия — опыт → метанавык через рефлексию
2. Перенос — применение метанавыка в новых контекстах
3. Сканирование — считывание норм, правил, иерархий
4. Оценка — анализ ресурсов и рисков
5. Проба — малые эксперименты и обратная связь
6. Регуляция границ — приспособиться, договориться, отстоять, уйти
7. Смыслообразование — нарратив «зачем я здесь»
8. Социальный обмен — сети, наставники, солидарность

### 3 уровня взаимодействия

- **Микро** — рефлексия и саморегуляция индивида
- **Мезо** — группа, команда, организация
- **Макро** — рынок труда, культура, институты

### Протокол «3Д» для практики

- **Диагностика** — карта опыта, среды, границ, профиля САК
- **Дизайн** — план малых проб, тренировка механизмов, поиск поддержки
- **Дебрифинг** — рефлексия после каждой пробы, пересборка идентичности, перенос

## Батарея тестирования

Интерактивный инструмент — **5 модулей**, двуязычный (RU / EN), ~25 минут, анонимно, без регистрации.

| Модуль | Содержание | Время |
|---|---|---|
| 1. Ситуационные задачи | 12 сценариев | ~7 мин |
| 2. Когнитивные тесты | Переключение правил, последовательности, рабочая память | ~6 мин |
| 3. Эмоциональные виньетки | 6 сценариев | ~4 мин |
| 4. Шкала самоотчёта | 21 пункт | ~4 мин |
| 5. Рефлексивный блок | 3 открытых вопроса | ~3 мин |

После прохождения формируется персональный отчёт: профиль по 7 компонентам, теги (ресурс / дефицит / баланс), интерпретация и рекомендации по протоколу «3Д».
